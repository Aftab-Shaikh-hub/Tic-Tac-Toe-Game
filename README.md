# Tic Tac Toe Game 🎮

A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript.

## Features
- Two-player gameplay
- Interactive user interface
- Real-time winner detection
- Draw detection
- Reset button to start a new game
- Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Play
1. Player 1 uses "X" and Player 2 uses "O".
2. Players take turns clicking on the empty boxes.
3. The first player to get three marks in a row wins.
4. If all boxes are filled without a winner, the game is a draw.
